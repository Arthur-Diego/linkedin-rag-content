# Research — LinkedIn technical content playbook (2026-08-09)

> Web research on high-performing tech/programming content (creators, copy data,
> algorithm reports). Drives the card design, the caption structure and
> `scripts/PROMPT_GERACAO.md`. Sources at the end.

## What top technical creators do

- **ByteByteGo / Alex Xu**: single large infographic, flat design, light background,
  numbered sequential flows (1→2→3 on arrows), short node labels, real tech names
  instead of generic boxes, one concept per image.
- **Level Up Coding / Nikki Siapno**: one visual card per concept, bold headline,
  "explained visually and practically" positioning.
- **Raul Junco**: hand-drawn (Excalidraw-style) diagrams + story-driven captions.
- **Brij Kishore Pandey**: cheatsheets/infographics, roadmap framing, ~daily cadence.
- Common: step-by-step flows, X-vs-Y comparisons, architecture boxes+arrows, brand
  mark on the card, consistent palette.

## Caption rules (data-backed)

| Rule | Evidence |
|---|---|
| First line ≤ 10 words, lead with a concrete number or contrarian claim | number-led hooks +34% likes (MagicPost, 1.2M posts) |
| NEVER open with a question | question hooks −34% likes |
| 700–1,000 characters for image posts | van der Blom 2025 (1.8M posts) |
| 1–2 line paragraphs, heavy white space, grade 5–7 language | AuthoredUp algorithm report |
| Real numbers/benchmarks in the body ("a number is a promise the post is concrete") | MagicPost |
| Close with a lesson/reflection + ONE easy question CTA | closers with question +72% |
| 0–3 niche hashtags at the end; no first-comment tags; no external links | consensus across sources |
| Optimize for saves: 1 save ≈ 5× the reach value of a like | AuthoredUp |

## Format & image rules

- 4:5 portrait (1080×1350 class) is the safe mobile-first feed ratio; vertical
  outperforms square (+32%, ContentIn). Our card: 1200×1350 ✓.
- Infographics: ~3× reach, 6× save rate vs plain posts (ContentIn 2025).
- Headline must be phone-legible without zooming; one key insight per card; short
  node labels (1–4 words); explicit background (never transparent).
- Document/PDF carousels are the top format (6.6% ER, 6–9 slides) — future evolution.
- Cadence: 3–5 posts/week, never more than 1/day (our cron: 3/week ✓).

## Diagram archetypes to rotate

1. Step-by-step numbered flow (pipeline stages).
2. X vs Y comparison (two branches, ❌/✅ outcomes).
3. Architecture boxes + labeled arrows (system-design style).
