# Privacy Policy

**App:** RAG Content Pipeline
**Owner:** Arthur Diego

This application is a personal automation tool used exclusively by its owner to
publish posts on the owner's own LinkedIn profile.

- It does not collect, store, or share any personal data from third parties.
- It only uses the LinkedIn API to (1) identify the authenticated member
  (`openid`, `profile`) and (2) create posts on that member's own profile
  (`w_member_social`).
- Access tokens are stored privately as GitHub Actions secrets and are never
  shared with anyone.
- No analytics, tracking, or advertising of any kind is performed.
